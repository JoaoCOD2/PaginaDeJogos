# Página de Jogos

Projeto de uma página de jogos em estilo cyberpunk com várias opções de minigames em HTML, CSS e JavaScript.

## 📁 Estrutura do Projeto

- `index.html` – página principal do catálogo com visual Cyber Arcade.
- `PaginaDeJogos/` – pasta com versão local ou recursos da página principal.
- `JogoDaVelha/` – jogo da velha com modo solo e multiplayer online via Firebase.
- `JogoFirebase_AdivinhacaoNumero/` – jogo de adivinhação de número com interface futurista.
- `JogoFirebase_PedraPapelTesoura/` – jogo Pedra, Papel e Tesoura com visual neon.
- `JogoGenius/` – jogo Genius/Simon com estilo original.

## 🎮 Jogos Incluídos

- **Jogo da Velha** (`JogoDaVelha/`)
  - Modo solo e multiplayer online.
  - Integração com Firebase Realtime Database.
  - Animação de vitória com linha de destaque.

- **Adivinhação de Número** (`AdivinhacaoNumero/`)
  - Interface moderna em estilo cyberpunk.
  - Controle de pontuação e mensagens de feedback.

- **Pedra, Papel e Tesoura** (`PedraPapelTesoura/`)
  - Interface compatível com o tema geral.
  - Animações e feedback visual.

- **Genius** (`JogoGenius/`)
  - Jogo de memória (Simon) com layout original.

## 🎨 Estilo e Visual

O projeto usa:

- Tema escuro com tons neon e vidro fosco.
- Fontes Google: `Orbitron` e `JetBrains Mono`.
- Efeito de glow, bordas brilhantes e movimento suave.
